15URDF와 로봇 모델 이해

so101_new_calib.urdf를 한 줄씩 해부하고, 조인트 한계표와 좌표 변환 체인을 직접 계산합니다.

시뮬레이터 열기 명령어 생성기

URDF란#

URDF(Unified Robot Description Format) 는 로봇의 구조를 기술하는 XML 파일입니다. ROS 2의 거의 모든 도구(RViz2, MoveIt 2, Gazebo, ros2_control)가 이 파일 하나를 읽고 동작합니다.

URDF가 담는 정보:

요소내용
<link>강체 부품. 시각 형상(visual), 충돌 형상(collision), 관성(inertial)
<joint>링크 사이 관절. 종류, 축, 원점, 한계
<material>색상·텍스처

SO-ARM101의 URDF 구하기#

세 가지 경로가 있습니다.

출처파일특징
TheRobotStudio/SO-ARM100Simulation/SO101/so101_new_calib.urdf공식 CAD에서 생성. 이 강좌의 기준
LeRobot 저장소내부 자산LeRobot 시각화용
URDF Studiourdf.d-robotics.cc브라우저에서 URDF를 편집·확인

이 강좌의 저장소에는 원본이 이미 포함되어 있습니다.

text
ros2_ws/src/so_arm101_description/urdf/so101_new_calib.urdf

파일 머리에는 생성 도구가 명시되어 있습니다.

xml
<?xml version="1.0" encoding="utf-8"?>
<!-- Generated using onshape-to-robot -->
<!-- Onshape https://cad.onshape.com/documents/7715cc284bb430fe6dab4ffd/... -->
<robot name="so101_new_calib">
onshape-to-robot

Onshape CAD 모델에서 URDF를 자동 생성하는 도구입니다. 그래서 원점 값들이 -8.97657e-09 처럼 지저분한 부동소수점으로 나옵니다. 사실상 0인 값들입니다.

링크 구조#

text
base_link
 └─ shoulder_link
     └─ upper_arm_link
         └─ lower_arm_link
             └─ wrist_link
                 └─ gripper_link
                     ├─ moving_jaw_so101_v1_link
                     └─ gripper_frame_link   (fixed, TCP)

각 링크는 세 가지 형상을 가집니다.

xml
<link name="upper_arm_link">
  <inertial>
    <origin xyz="-0.0898471 -0.00838224 0.0184089" rpy="0 0 0"/>
    <mass value="0.1"/>
    <inertia ixx="..." .../>
  </inertial>
  <visual>
    <origin xyz="-0.11257 -0.0155 0.0187" rpy="-3.14159 0 -1.5708"/>
    <geometry><mesh filename="package://so_arm101_description/meshes/upper_arm.stl"/></geometry>
    <material name="3d_printed"/>
  </visual>
  <collision>
    <origin xyz="-0.11257 -0.0155 0.0187" rpy="-3.14159 0 -1.5708"/>
    <geometry><mesh filename="package://so_arm101_description/meshes/upper_arm.stl"/></geometry>
  </collision>
</link>
요소용도주의
visualRViz·Gazebo에 그려지는 모습정밀한 메시 OK
collision충돌 검사단순할수록 좋음. 메시가 복잡하면 플래닝이 느려짐
inertial물리 시뮬레이션Gazebo에서 필수. 값이 이상하면 로봇이 날아감
충돌 형상 최적화

MoveIt 2 플래닝이 느리다면 collision 지오메트리를 STL 대신 박스/실린더 프리미티브로 바꾸는 것이 가장 효과적입니다. 이 강좌의 so_arm101_description 패키지는 프리미티브 버전을 xacro 옵션으로 제공합니다.

SO-ARM101의 6개 조인트를 URDF 원문 값 그대로 정리했습니다.

이 강좌의 시뮬레이터와 파이썬 스크립트는 위 값을 그대로 씁니다.

bash

실습 — 손으로 검증하기
  1. 위 FK 결과를 메모합니다.
  2. 시뮬레이터에서 같은 각도를 슬라이더로 입력합니다.
  3. TCP 좌표 표시가 같은 값을 보이는지 확인합니다.

같다면 여러분은 URDF 변환 체인을 제대로 이해한 것입니다.

xacro로 확장하기#

URDF는 매크로가 없어 반복이 많습니다. ROS 2에서는 xacro(XML Macro)로 감싸 쓰는 것이 표준입니다.

xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="so_arm101">

  <xacro:arg name="hardware_type" default="mock"/>
  <xacro:arg name="usb_port"      default="/dev/ttyACM0"/>

  <!-- 순수 기구 구조 -->
  <xacro:include filename="$(find so_arm101_description)/urdf/so101_macro.xacro"/>
  <xacro:so101_arm prefix=""/>

  <!-- ros2_control 하드웨어 인터페이스 -->
  <xacro:include filename="$(find so_arm101_description)/urdf/so101.ros2_control.xacro"/>
  <xacro:so101_ros2_control
      name="SOArm101System"
      hardware_type="$(arg hardware_type)"
      usb_port="$(arg usb_port)"/>

</robot>

xacro를 URDF로 펼쳐 보려면:

bash
ros2 run xacro xacro src/so_arm101_description/urdf/so_arm101.urdf.xacro > /tmp/so101.urdf
check_urdf /tmp/so101.urdf

check_urdf는 링크·조인트 트리가 올바른지 검증하고 구조를 출력합니다.

bash
urdf_to_graphiz /tmp/so101.urdf   # 트리 다이어그램 PDF 생성
