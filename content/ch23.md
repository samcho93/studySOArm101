## 무료 공식 강좌

### Hugging Face Robotics Course

- [huggingface.co/learn/robotics-course](https://huggingface.co/learn/robotics-course/en/unit0/1)
- LeRobot을 만든 팀이 직접 만든 **무료 자기주도 강좌**입니다.
- **실물 로봇이 없어도 됩니다.** 시뮬레이션 환경과 공개 데이터셋으로 전 과정을 따라갈 수 있습니다.
- 구성: Unit 0 소개 → Unit 1 로봇 학습과 LeRobot 생태계 → Unit 2 고전 로보틱스 →
  (준비 중) Unit 5 강화학습 · Unit 6 모방학습 · Unit 7 파운데이션 모델
- 선수 지식: 기초 파이썬, 선형대수·미적분 맛보기 정도

:::tip 이 강좌와의 관계
HF 강좌는 **이론과 알고리즘**에 무게가 있고, 이 강좌는 **SO-ARM101 실물과 ROS 2**에
무게가 있습니다. 13~14장을 더 깊이 파고 싶다면 HF 강좌 Unit 6을 이어서 보세요.
:::

### NVIDIA — Train an SO-101 Robot From Sim-to-Real With NVIDIA Isaac

- [docs.nvidia.com/learning/physical-ai/sim-to-real-so-101](https://docs.nvidia.com/learning/physical-ai/sim-to-real-so-101/latest/)
- **SO-101을 명시적으로 다루는 NVIDIA 공식 학습 경로**입니다.
- 목표 과제: 원심분리기 바이알을 랙에 꽂는 **비정형 픽앤플레이스**를 시뮬레이션에서
  학습해 실기로 옮기기
- 16개 모듈 / 5개 묶음: 개요(4) → 로봇 랩 구축(4) → 데이터 수집·학습·평가(4) →
  데이터셋 증강(2) → 구동 격차 측정(2)
- 사용 스택: **Isaac Sim**, **GR00T**(VLA), **SAGE+GapONet**(액추에이터 격차 추정), **LeRobot**
- 도메인 랜덤화를 포함한 **네 가지 Sim2Real 전략**을 비교합니다.

:::tip 12장의 확장판입니다
이 강좌 [12장](~/lessons/ch12.html)에서 다룬 LeIsaac이 "시뮬레이션에서 데이터를 모으는 법"이라면,
NVIDIA 과정은 **"시뮬레이션과 실물의 차이를 어떻게 측정하고 좁히는가"** 를 정면으로 다룹니다.
:::

## 한국어 자료

### RoboSEasy Docs

- [roboseasy.github.io — SO ARM 시작하기](https://roboseasy.github.io/docs/physical-ai/lerobot/so-arm/)
- 한국 키트 판매사가 운영하는 **한국어 문서**입니다. 구성:
  - 소프트웨어 준비 / 하드웨어 조립 / USB·카메라 포트 설정
  - **원터치 셋업 스크립트**, 모터 제어 GUI
  - 캘리브레이션 · 텔레오퍼레이션 · 녹화/재생
  - 정책: ACT, SmolVLA, GR00T N1.5
- 조립 가이드가 **"조립 전에 모터 설정을 먼저 하라"** 는 점을 이 강좌 [4장](~/lessons/ch04.html)과
  동일하게 강조합니다.
- 국내 구매 기준 가격 정보(리더+팔로워 약 50만 원대, 카메라 홀더 포함 키트 55만 원대)가
  정리되어 있습니다.

### soarm101-console (한국어 프로젝트)

- [github.com/sesepark/soarm101-console](https://github.com/sesepark/soarm101-console)
- **문서가 한국어**인 국내 개발 오픈소스입니다. 브라우저 하나로 진단·캘리브레이션·
  텔레오퍼레이션·데이터 수집·학습·정책 실행을 묶었습니다.
- 눈여겨볼 설계:
  - **물리 리더 암 없이도** 브라우저 3D 가상 리더로 팔로워를 조종
  - 워치독·페일세이프가 붙은 **안전 게이트 텔레오퍼레이션**
  - 파일 락으로 **장치 단독 점유**를 강제 (시리얼 포트 충돌 방지 — [17장](~/lessons/ch17.html) 참고)
  - 정책 실행 시 **소프트 스타트**로 팔이 튀는 것을 방지
  - DGX Spark 원격 학습 연동, 하드웨어 없이 도는 테스트 300여 개
- 스택: Python 3.12, FastAPI, LeRobot, three.js, OpenCV

:::tip 이 강좌의 시뮬레이터와 비슷한 발상
이 강좌의 [3D 시뮬레이터](~/sim/index.html)도 "물리 리더 없이 팔로워를 조종해 본다"는
같은 문제의식에서 출발했습니다. 한 걸음 더 나아가 **실제 하드웨어까지 연결**하고
싶다면 이 프로젝트가 좋은 참고가 됩니다.
:::
