23더 배우기 — 강좌·프로젝트·용어

HF·NVIDIA 공식 강좌, Seeed 벤더 위키, 한국어 자료, 응용 프로젝트, 중↔한 용어 대조표.

시뮬레이터 열기 URDF 뷰어 명령어 생성기

이 강좌를 끝냈다면 다음은 다른 사람이 만든 것을 읽고, 내 것에 이식하는 단계입니다. 아래는 SO-ARM101을 다루는 공개 자료를 종류별로 정리한 것입니다.

링크 확인 시점

2026년 9월 기준으로 접근을 확인한 링크입니다. 로봇 생태계는 변화가 빨라 경로가 바뀔 수 있으니, 끊긴 링크는 저장소 이름으로 검색해 보세요.

무료 공식 강좌#

Hugging Face Robotics Course#

  • huggingface.co/learn/robotics-course
  • LeRobot을 만든 팀이 직접 만든 무료 자기주도 강좌입니다.
  • 실물 로봇이 없어도 됩니다. 시뮬레이션 환경과 공개 데이터셋으로 전 과정을 따라갈 수 있습니다.
  • 구성: Unit 0 소개 → Unit 1 로봇 학습과 LeRobot 생태계 → Unit 2 고전 로보틱스 →

(준비 중) Unit 5 강화학습 · Unit 6 모방학습 · Unit 7 파운데이션 모델

  • 선수 지식: 기초 파이썬, 선형대수·미적분 맛보기 정도
이 강좌와의 관계

HF 강좌는 이론과 알고리즘에 무게가 있고, 이 강좌는 SO-ARM101 실물과 ROS 2에 무게가 있습니다. 13~14장을 더 깊이 파고 싶다면 HF 강좌 Unit 6을 이어서 보세요.

NVIDIA — Train an SO-101 Robot From Sim-to-Real With NVIDIA Isaac#

  • docs.nvidia.com/learning/physical-ai/sim-to-real-so-101
  • SO-101을 명시적으로 다루는 NVIDIA 공식 학습 경로입니다.
  • 목표 과제: 원심분리기 바이알을 랙에 꽂는 비정형 픽앤플레이스를 시뮬레이션에서

학습해 실기로 옮기기

  • 16개 모듈 / 5개 묶음: 개요(4) → 로봇 랩 구축(4) → 데이터 수집·학습·평가(4) →

데이터셋 증강(2) → 구동 격차 측정(2)

  • 사용 스택: Isaac Sim, GR00T(VLA), SAGE+GapONet(액추에이터 격차 추정), LeRobot
  • 도메인 랜덤화를 포함한 네 가지 Sim2Real 전략을 비교합니다.
12장의 확장판입니다

이 강좌 12장에서 다룬 LeIsaac이 "시뮬레이션에서 데이터를 모으는 법"이라면, NVIDIA 과정은 "시뮬레이션과 실물의 차이를 어떻게 측정하고 좁히는가" 를 정면으로 다룹니다.

soarm101-console (한국어 프로젝트)#

  • github.com/sesepark/soarm101-console
  • 문서가 한국어인 국내 개발 오픈소스입니다. 브라우저 하나로 진단·캘리브레이션·

텔레오퍼레이션·데이터 수집·학습·정책 실행을 묶었습니다.

  • 눈여겨볼 설계:
    • 물리 리더 암 없이도 브라우저 3D 가상 리더로 팔로워를 조종
    • 워치독·페일세이프가 붙은 안전 게이트 텔레오퍼레이션
    • 파일 락으로 장치 단독 점유를 강제 (시리얼 포트 충돌 방지 — 17장 참고)
    • 정책 실행 시 소프트 스타트로 팔이 튀는 것을 방지
    • DGX Spark 원격 학습 연동, 하드웨어 없이 도는 테스트 300여 개
  • 스택: Python 3.12, FastAPI, LeRobot, three.js, OpenCV
이 강좌의 시뮬레이터와 비슷한 발상

이 강좌의 3D 시뮬레이터도 "물리 리더 없이 팔로워를 조종해 본다"는 같은 문제의식에서 출발했습니다. 한 걸음 더 나아가 실제 하드웨어까지 연결하고 싶다면 이 프로젝트가 좋은 참고가 됩니다.
