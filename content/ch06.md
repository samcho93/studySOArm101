## 설치 전략

LeRobot은 기본 패키지를 **가볍게** 유지하고, 필요한 기능을 **extras**로 추가하는 구조입니다. SO-ARM101에 필요한 조합은 정해져 있습니다.

| 목적 | 필요한 extra |
| --- | --- |
| 실기 제어 (녹화·재생·캘리브레이션) | `core_scripts` (= `dataset` + `hardware` + `viz`) |
| **Feetech 서보 제어** | `feetech` ← **SO-ARM101 필수** |
| 정책 학습 | `training` |
| SmolVLA / π0 등 | `smolvla`, `pi`, `diffusion` |

:::tip 원문 위키의 최소 조합
원문 튜토리얼은 소스 클론 후 **`pip install -e ".[feetech]"`** 하나만 실행합니다. 이것으로 텔레오퍼레이션까지는 충분합니다. 데이터 녹화와 학습까지 하려면 `".[feetech,core_scripts,training]"` 을 권장합니다.
:::

## 공통 절차

### 1. Miniconda / Miniforge 설치

- 배포 페이지: [anaconda.com/download](https://www.anaconda.com/download)
- Windows 직접 다운로드: `https://repo.anaconda.com/miniconda/Miniconda3-latest-Windows-x86_64.exe`
- Linux에서는 miniforge도 좋습니다.

```bash
wget "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh
```

:::info uv를 선호한다면
`conda` 대신 `uv`나 `venv`를 써도 됩니다. **Python ≥ 3.12**, **PyTorch ≥ 2.10** 을 만족하면 됩니다.
```bash
uv python install 3.12
uv venv --python 3.12
```
:::

### 2. 가상환경 생성과 활성화

```bash
conda create -y -n lerobot python=3.12
conda activate lerobot
```

:::warn 매번 활성화해야 합니다
새 터미널을 열 때마다 `conda activate lerobot`을 실행해야 합니다. 이걸 빼먹어서 "명령을 찾을 수 없음" 오류를 겪는 경우가 가장 흔합니다.
:::

### 3. ffmpeg 설치 (영상 디코딩)

LeRobot은 기본적으로 **TorchCodec**으로 영상을 디코딩하며, 이는 `ffmpeg`를 필요로 합니다.

```bash
conda install ffmpeg=7.1.1 -c conda-forge -y
```

설치 확인:

```bash
ffmpeg
```

:::info 버전을 왜 7.1.1로 고정하나
`conda install ffmpeg -c conda-forge`는 보통 ffmpeg 8.x(libsvtav1 인코더 포함)를 설치합니다. 하지만 torchcodec과 버전이 어긋나거나 `libsvtav1`이 빠지는 사례가 있어, 원문 튜토리얼은 **7.1.1 고정**을 권장합니다. `ffmpeg -encoders`로 `libsvtav1` 존재를 확인할 수 있습니다.

PyTorch ≥ 2.10 (TorchCodec ≥ 0.10)부터는 시스템 ffmpeg에 동적 링크가 가능해서 `sudo apt install ffmpeg`로도 됩니다. 그 이전 버전은 반드시 conda 쪽 ffmpeg를 쓰세요.

TorchCodec을 지원하지 않는 플랫폼(Linux ARM, PyTorch < 2.8인 Windows)에서는 LeRobot이 자동으로 `pyav`로 폴백하므로 ffmpeg 설치를 건너뛰어도 됩니다.
:::

### 4. LeRobot 소스 받기

```bash
git clone https://github.com/huggingface/lerobot.git
cd lerobot
```

### 5. 설치

```bash
pip install -e ".[feetech]"
```

데이터 녹화·학습까지 한 번에 하려면:

```bash
pip install -e ".[feetech,core_scripts,training]"
```

전부 설치하려면:

```bash
pip install -e ".[all]"
```

PyPI에서 바로 설치하는 방법도 있습니다.

```bash
pip install 'lerobot[feetech,core_scripts]'
```

### 6. 설치 검증

```bash
lerobot-info
```

```bash
python
```

```python
import lerobot
lerobot.__version__

import torch
torch.cuda.is_available()      # NVIDIA GPU가 있으면 True

import scservo_sdk             # Feetech SDK. 오류 없이 import되면 OK
```

:::check 성공 기준
- `lerobot-info` 가 버전과 환경 정보를 출력
- `import scservo_sdk` 가 오류 없음 ← **Feetech extra가 제대로 설치된 증거**
- (GPU 사용 시) `torch.cuda.is_available()` 이 `True`
:::

## 플랫폼별 추가 사항

### Ubuntu

빌드 오류가 난다면 시스템 의존성을 먼저 설치하세요.

```bash
sudo apt-get install cmake build-essential python3-dev pkg-config \
  libavformat-dev libavcodec-dev libavdevice-dev libavutil-dev \
  libswscale-dev libswresample-dev libavfilter-dev
```

시리얼 포트 권한은 [7장](~/lessons/ch07.html)에서 다룹니다.

### Windows

- Miniconda 설치 시 **"Add to PATH"** 를 체크하거나, "Anaconda Prompt"를 사용하세요.
- Windows에서는 `lerobot-record`의 **키보드 원격조작**이 동작하지만, WSL이나 헤드리스 환경에서는 제약이 있습니다.
- CUDA는 PyPI 기본 휠이 Windows용 CUDA 빌드를 포함합니다. 별도 인덱스 지정이 보통 필요 없습니다.

:::tip Windows에서 ROS 2까지 하려면
15~20장의 ROS 2 실습은 **WSL2 + Ubuntu 22.04(Humble)** 또는 **Ubuntu 24.04(Jazzy)** 를 권장합니다. WSL에서 USB 시리얼을 쓰려면 `usbipd-win`으로 장치를 WSL에 연결해야 합니다.

```powershell
winget install usbipd
usbipd list
usbipd bind --busid <BUSID>
usbipd attach --wsl --busid <BUSID>
```
:::

### WSL (Windows Subsystem for Linux)

키보드 입력 처리를 위해 `evdev`가 추가로 필요합니다.

```bash
conda install evdev -c conda-forge
```

uv 사용 시:

```bash
sudo apt install libevdev-dev
uv pip install evdev
```

### Jetson (Orin Nano / NX)

- JetPack에 포함된 PyTorch를 쓰거나 NVIDIA가 배포하는 aarch64 휠을 설치하세요. PyPI의 기본 torch는 Jetson에서 동작하지 않습니다.
- Linux ARM(aarch64)은 TorchCodec 미지원이므로 `pyav`로 자동 폴백됩니다.

## 네트워크가 느릴 때 — 미러 설정 (선택)

중국 등 특정 지역에서 패키지 다운로드가 느릴 때 쓰는 설정입니다. 국내(한국)에서는 보통 필요 없습니다.

pip 미러:

```bash
pip config set global.index-url https://mirrors.aliyun.com/pypi/simple
```

conda 미러 (Linux):

```bash
echo "" > ~/.condarc
cat << EOF > ~/.condarc
channels:
  - defaults
show_channel_urls: true
default_channels:
  - https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main
  - https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/r
  - https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/msys2
custom_channels:
  conda-forge: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  msys2: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  bioconda: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  menpo: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  pytorch: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
EOF
conda clean -i
```

conda 미러 (Windows):

```bash
conda config --remove-key channels
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/
conda config --set show_channel_urls yes
conda clean -i
conda config --show-sources
```

:::info 한국에서는
기본 PyPI/conda-forge 속도가 충분합니다. 미러를 잘못 설정하면 오히려 패키지 충돌이 나므로 **문제가 없다면 건드리지 마세요.**
:::

## Hugging Face 계정 연동 (선택, 11장 이후 필요)

데이터셋과 모델을 Hub에 올리려면 **쓰기 권한이 있는 토큰**이 필요합니다. [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) 에서 발급합니다.

```bash
hf auth login --token ${HUGGINGFACE_TOKEN} --add-to-git-credential
```

사용자 이름을 변수에 저장해 두면 이후 명령이 편합니다.

```bash
HF_USER=$(NO_COLOR=1 hf auth whoami | awk -F': *' 'NR==1 {print $2}')
echo $HF_USER
```

:::warn 토큰은 비밀입니다
토큰을 스크립트나 저장소에 하드코딩하지 마세요. 환경 변수나 `hf auth login`으로만 관리하세요.
:::

## 설치 문제 해결

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| `lerobot-find-port: command not found` | 가상환경 미활성화 | `conda activate lerobot` |
| `ModuleNotFoundError: scservo_sdk` | feetech extra 미설치 | `pip install -e ".[feetech]"` |
| `torchcodec` 관련 오류 | ffmpeg 버전 불일치 | `conda install ffmpeg=7.1.1 -c conda-forge` |
| `libsvtav1` 없음 | ffmpeg 빌드에 인코더 누락 | 위와 동일 / `ffmpeg -encoders`로 확인 |
| PyAV 빌드 실패 | 시스템 ffmpeg 개발 헤더 없음 | 위 `apt-get install` 목록 실행 |
| `torch.cuda.is_available()` 가 False | CPU 전용 휠 설치됨 | 드라이버 확인 후 CUDA 인덱스 지정 재설치 |

Linux에서 특정 CUDA 버전을 지정하려면:

```bash
pip install --index-url https://download.pytorch.org/whl/cu128 torch torchvision
pip install -e ".[all]"
```
