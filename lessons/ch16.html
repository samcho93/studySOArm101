PART 5 ROS 2 연동과 시뮬레이션 · 약 35분

16ROS 2 워크스페이스 구성과 RViz2

so_arm101_description 패키지를 만들고 robot_state_publisher·RViz2로 모델을 띄웁니다.

시뮬레이터 열기 URDF 뷰어 명령어 생성기

환경 준비#

어떤 배포판을 쓸까
  • Ubuntu 22.04 + ROS 2 Humble — 원문 위키의 SO-ARM101 ROS 2 패키지가 기준으로 삼는 조합. 자료가 가장 많습니다.
  • Ubuntu 24.04 + ROS 2 Jazzy — 최신. Gazebo Harmonic과의 궁합이 좋습니다.

이 강좌의 명령은 Humble 기준으로 적고, Jazzy에서 다른 부분은 따로 표시합니다.

시스템 요구사항#

  • Ubuntu 22.04 (권장) 또는 24.04
  • 메모리 최소 4GB
  • 실기 모드는 USB 시리얼 포트 필요

ROS 2 Humble 설치#

bash
# locale 설정
sudo apt update && sudo apt install locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

# ROS 2 저장소 추가
sudo apt install software-properties-common
sudo add-apt-repository universe
sudo apt update && sudo apt install curl -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

# ROS 2 Humble Desktop 설치
sudo apt update
sudo apt install ros-humble-desktop

빌드 도구와 의존 패키지#

bash
# colcon 빌드 도구
sudo apt install python3-colcon-common-extensions

# MoveIt 2
sudo apt install ros-humble-moveit

# ros2_control
sudo apt install ros-humble-ros2-control \
                 ros-humble-ros2-controllers \
                 ros-humble-controller-manager \
                 ros-humble-joint-state-publisher-gui

Jazzy를 쓴다면 humble을 jazzy로 바꾸면 됩니다.

환경 변수#

bash
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc

시리얼 포트 권한 (실기 필수)#

영구 설정 (권장):

bash
sudo usermod -a -G dialout $USER
# 로그아웃 후 다시 로그인해야 적용됩니다

임시 설정:

bash
sudo chmod 666 /dev/ttyACM0

워크스페이스 만들기#

bash
# 1단계 — 워크스페이스 생성
mkdir -p ~/so101_ws/src
cd ~/so101_ws/src

# 2단계 — 소스 배치
cp -r /path/to/studySO-ARM101/ros2_ws/src/* ./

# 3단계 — 시스템 의존성 설치
cd ~/so101_ws
rosdep install --from-paths src --ignore-src -r -y

# 4단계 — 전체 빌드
colcon build --symlink-install

# 5단계 — 환경 로드 (새 터미널마다 필요!)
source install/setup.bash
새 터미널마다 source

source ~/so101_ws/install/setup.bash를 잊으면 Package 'so_arm101_description' not found 오류가 납니다. ~/.bashrc에 추가해 두면 편합니다.

별도 드라이버 설치가 필요 없습니다

so_arm_hardware 패키지가 내장되어 있어, 시리얼로 SCS 프로토콜을 써서 STS3215 서보와 직접 통신합니다. 추가 드라이버를 설치할 필요가 없습니다.

1단계 — 시각화 검증 (가장 쉬움)#

컨트롤러도, 하드웨어도 필요 없습니다.

bash
source ~/so101_ws/install/setup.bash
ros2 launch so_arm101_description view_description.launch.py rviz:=true

RViz2가 열리며 로봇 모델 전체가 표시됩니다. joint_state_publisher_gui의 슬라이더를 움직여 각 관절이 올바른 축으로, 올바른 방향으로 도는지 확인하세요.

여기서 확인할 것
  • [ ] 6개 관절이 모두 슬라이더에 나타나는가
  • [ ] 각 관절이 예상한 축으로 회전하는가
  • [ ] 메시가 제대로 로드되는가 (흰 상자만 보이면 메시 경로 문제)
  • [ ] TF 트리가 base_link → ... → gripper_frame_link 로 이어지는가

이 런치가 실행하는 노드#

노드역할
robot_state_publisherURDF + /joint_states → TF 변환 발행
joint_state_publisher_gui슬라이더로 /joint_states 발행
rviz2시각화

유용한 확인 명령#

bash
# 토픽 목록
ros2 topic list

# 현재 관절 상태
ros2 topic echo /joint_states --once

# TF 트리를 PDF로 저장
ros2 run tf2_tools view_frames

# 특정 변환 조회 (베이스 → TCP)
ros2 run tf2_ros tf2_echo base_link gripper_frame_link

tf2_echo 출력이 15장에서 계산한 FK 결과와 일치하는지 비교해 보세요.

2단계 — 컨트롤러 테스트 (Mock 하드웨어)#

여전히 실물 로봇이 필요 없습니다. 모든 것이 메모리에서 돕니다.

bash
ros2 launch so_arm101_description controllers_bringup.launch.py

로그에 다음이 나오면 준비 완료입니다.

text
joint_state_broadcaster      → active
joint_trajectory_controller  → active
Mock 모드의 컨트롤러 구성

시뮬레이션 모드는 두 개의 컨트롤러만 띄웁니다.

  • joint_state_broadcaster — 하드웨어 상태를 /joint_states로 발행
  • joint_trajectory_controller — 6개 관절 전체(그리퍼 포함)의 궤적 실행

별도의 gripper_controller는 제거되었고, 그리퍼도 joint_trajectory_controller가 함께 제어합니다.

컨트롤러 상태 확인#

bash
ros2 control list_controllers
ros2 control list_hardware_interfaces

직접 궤적 명령 보내기#

bash
ros2 topic pub --once /joint_trajectory_controller/joint_trajectory \
  trajectory_msgs/msg/JointTrajectory \
  "{
    joint_names: [shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll, gripper],
    points: [{
      positions: [0.0, -0.6, 0.9, 0.6, 0.0, 0.6],
      time_from_start: {sec: 3}
    }]
  }"

RViz2에서 팔이 3초에 걸쳐 그 자세로 이동합니다.

이 명령이 중요한 이유

20장에서 LeRobot 정책의 출력을 ROS 2로 보낼 때 정확히 이 메시지 형식을 씁니다. 지금 손에 익혀 두세요.

RViz2 활용#

필수 디스플레이#

디스플레이용도
RobotModelURDF 렌더링. Description Topic을 /robot_description으로
TF좌표계 표시. 링크가 많으면 필요한 프레임만 켜기
MotionPlanningMoveIt 2 패널 (18장)
Grid바닥 격자

설정 저장#

RViz2 설정을 so_arm101_description/rviz/view.rviz로 저장해 두면 런치 파일에서 자동으로 불러옵니다.

python
Node(
    package="rviz2", executable="rviz2",
    arguments=["-d", PathJoinSubstitution([
        FindPackageShare("so_arm101_description"), "rviz", "view.rviz"
    ])],
)

빌드 문제 해결#

증상원인해결
package not found시스템 의존성 미설치 또는 source 누락rosdep install ... 후 source /opt/ros/humble/setup.bash
메시가 안 보임package:// 경로 오류meshes/ 디렉터리 위치와 CMakeLists.txt install 규칙 확인
colcon build 실패컴파일러 또는 의존성로그의 첫 에러부터 해결. --packages-select로 하나씩 빌드
RViz2가 매우 느림충돌 메시가 너무 복잡프리미티브 충돌 형상 사용
/joint_states 가 비어 있음publisher 노드 미실행joint_state_publisher_gui 실행 확인
xacro 파싱 오류인자 누락ros2 run xacro xacro <파일> 로 단독 실행해 에러 확인
패키지 하나만 다시 빌드
bash
colcon build --packages-select so_arm101_description --symlink-install

--symlink-install을 쓰면 URDF·런치·설정 파일 수정 시 재빌드 없이 반영됩니다.
