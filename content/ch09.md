## 텔레오퍼레이션이란

사람이 **리더 암**을 손으로 움직이면, 그 관절 각도를 읽어 **팔로워 암**에 그대로 명령으로 보내는 것입니다. 구조는 놀랍도록 단순합니다.

```python
while True:
    action = teleop_device.get_action()   # 리더의 현재 관절 각도를 읽는다
    robot.send_action(action)             # 팔로워에게 그 각도로 가라고 명령한다
```

이게 전부입니다. 초당 30~60회 반복하면 팔로워가 리더를 실시간으로 따라옵니다.

:::info 왜 이 단순한 구조가 중요한가
모방학습 데이터셋의 `action`은 바로 이 리더의 관절 각도입니다. 즉 **텔레오퍼레이션을 하는 것 자체가 데이터 수집**입니다. ([11장](~/lessons/ch11.html))
:::

---

@fig[teleop-loop] 리더에서 읽은 각도가 팔로워 명령이면서 동시에 데이터셋의 정답이 됩니다.

## 먼저 시뮬레이터에서 체험하기

실물을 켜기 전에 감을 잡아 두면 사고를 줄일 수 있습니다.

:::task 실습 — 시뮬레이터 텔레오퍼레이션
[3D 시뮬레이터](~/sim/index.html)를 열고 **"텔레오퍼레이션" 탭**을 선택하세요.

1. 화면에 **반투명한 리더 암**과 **불투명한 팔로워 암**이 함께 나타납니다.
2. 슬라이더나 IK 타깃으로 **리더**를 움직이면 팔로워가 약간의 지연을 두고 따라옵니다.
3. **"추종 지연(lag)" 슬라이더**를 올려 보세요. 실제 시리얼 통신 지연과 서보 응답 지연을 모사한 것입니다. 지연이 크면 빠른 동작에서 팔로워가 뒤처지는 것을 볼 수 있습니다.
4. **"조인트 한계 초과 경고"** 를 켜 두면, 리더가 팔로워의 물리적 한계를 넘는 자세를 만들 때 해당 관절이 빨갛게 표시됩니다. 실물에서 이 상황이 바로 서보 과부하입니다.
:::

## 실물 텔레오퍼레이션 실행

### 기본 명령

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_awesome_follower_arm \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --teleop.id=my_awesome_leader_arm
```

macOS 예시 (`/dev/tty.usbmodem*` 또는 `/dev/tty.wchusbserial*` 둘 다 동작):

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/tty.usbmodem5AAF2193061 \
    --robot.id=my_follower_arm \
    --teleop.type=so101_leader \
    --teleop.port=/dev/tty.usbmodem5AAF2194741 \
    --teleop.id=my_leader_arm
```

:::tip 포트 이름은 명령어 생성기로
[명령어 생성기](~/tools/cli-builder.html)에 포트와 id를 입력해 두면 위 명령이 자동 완성됩니다.
:::

### 이 명령이 하는 일

1. 캘리브레이션 파일이 있는지 확인하고, 없으면 **캘리브레이션 절차를 먼저 시작**합니다.
2. 리더와 팔로워를 연결합니다.
3. 텔레오퍼레이션 루프를 시작합니다.

### 파이썬 API 버전

```python
from lerobot.teleoperators.so_leader import SO101Leader, SO101LeaderConfig
from lerobot.robots.so_follower import SO101Follower, SO101FollowerConfig

robot_config = SO101FollowerConfig(
    port="/dev/ttyACM0",
    id="my_follower_arm",
)

teleop_config = SO101LeaderConfig(
    port="/dev/ttyACM1",
    id="my_leader_arm",
)

robot = SO101Follower(robot_config)
teleop_device = SO101Leader(teleop_config)
robot.connect()
teleop_device.connect()

while True:
    action = teleop_device.get_action()
    robot.send_action(action)
```

## 첫 실행 안전 수칙

:::danger 처음 켤 때 반드시
1. **팔로워 주변을 비우세요.** 반경 60cm 안에 물건·사람·케이블이 없어야 합니다. (최대 도달 반경이 약 48cm입니다)
2. **전원 플러그를 손이 닿는 곳에** 두세요. 이상이 생기면 즉시 뽑을 수 있어야 합니다.
3. **리더를 아주 천천히** 움직이세요. 팔로워가 어떻게 반응하는지 먼저 관찰합니다.
4. 베이스가 **클램프로 고정**되어 있는지 확인하세요.
5. 터미널에서 **Ctrl+C** 로 언제든 멈출 수 있습니다.
:::

### 정상 동작 판정

| 관찰 | 판정 |
| --- | --- |
| 리더를 움직이면 팔로워가 **같은 방향**으로 따라옴 | 정상 |
| 팔로워가 **반대 방향**으로 움직임 | 서보 ID 배치 오류 또는 drive_mode 문제 |
| 팔로워가 **덜덜 떨림** | 전원 용량 부족 또는 통신 지연 |
| 팔로워가 **한 관절만 안 움직임** | 그 관절 캘리브레이션 범위 0 |
| 팔로워가 **급격히 튐** | 캘리브레이션 불일치 — 즉시 정지 |
| 리더가 **손으로 안 움직임** | 리더 토크가 켜져 있음 |

## 그리퍼 동작

리더의 **트리거**를 당기면 팔로워의 **그리퍼가 닫힙니다.** 트리거도 하나의 서보(ID 6)이므로, 다른 관절과 똑같이 각도가 전달됩니다.

:::warn 그리퍼는 힘 제한이 없습니다
STS3215는 위치 제어이므로, 물체를 잡은 상태에서 트리거를 더 당기면 **서보가 계속 힘을 줍니다.** 과도하게 당기면 그리퍼 부품이 깨지거나 서보가 과열됩니다. 물체를 잡는 순간 트리거를 멈추는 감각을 익히세요.
:::

## 시각화와 함께 보기 (`rerun`)

관절 값과 카메라 영상을 실시간 그래프로 보려면 `--display_data=true`를 추가합니다. (카메라 설정은 [10장](~/lessons/ch10.html))

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_follower_arm \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --teleop.id=my_leader_arm \
    --display_data=true
```

`rerun` 뷰어가 열리고 각 관절의 목표값(action)과 실제값(observation)이 그래프로 그려집니다.

:::tip 추종 오차 읽기
action과 observation 곡선 사이의 간격이 **추종 오차**입니다. 빠르게 움직일수록 벌어지는데, 이 간격이 크면 데이터셋 품질이 떨어집니다. 데이터 수집 시 **동작 속도를 일정하게, 너무 빠르지 않게** 유지해야 하는 이유입니다.
:::

## 대안 — 리더 암 없이 조종하기

리더 암이 아직 없거나 고장 났다면 다른 입력 장치를 쓸 수 있습니다.

| 방식 | 설명 |
| --- | --- |
| **키보드** | `--teleop.type=keyboard`. 관절을 키로 증감. 정밀하지 않지만 테스트에 유용 |
| **게임패드** | `--teleop.type=gamepad`. 아날로그 스틱으로 관절 제어 |
| **휴대폰** | LeRobot의 [phone_teleop](https://huggingface.co/docs/lerobot/main/en/phone_teleop) — 폰 자세로 팔로워를 제어 |
| **LeLab 웹 UI** | [github.com/huggingface/leLab](https://github.com/huggingface/leLab) — 캘리브레이션·텔레오퍼레이션·녹화·학습·재생을 브라우저 하나로 |
| **ESP32-S3 무선** | 원문 위키의 무선 텔레오퍼레이션 프로젝트 |

:::info 키보드 텔레오퍼레이션 제약
키보드 텔레오퍼레이션은 **전역 키 입력 백엔드**가 필요합니다. X11 세션, Windows 데스크톱, 또는 손쉬운 사용 권한이 부여된 macOS에서만 동작하며 **Wayland나 헤드리스 환경에서는 불가**합니다.

(녹화 중 에피소드 제어 키 `n`/`r`/`q`는 별개로, 터미널에서 직접 읽기 때문에 Wayland·헤드리스·SSH에서도 동작합니다.)
:::

저장소에 포함된 간단한 키보드 텔레오퍼레이션 예제도 참고하세요.

```bash
python scripts/so101_keyboard_teleop.py --port /dev/ttyACM0 --id my_follower_arm
```

## 문제 해결

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| `Permission denied` | 시리얼 권한 | [7장](~/lessons/ch07.html) 권한 설정 |
| `Could not find port` | 포트 이름 오타 / USB 미연결 | `lerobot-find-port` 재실행 |
| 팔로워 무반응 | 외부 전원 미연결 | 12V 어댑터 확인 |
| 팔로워가 축 처짐 | 토크 미활성 또는 전원 부족 | 전원 용량(5A) 확인 |
| 좌우가 반대 | 리더/팔로워 포트 바뀜 | `--robot.port`와 `--teleop.port` 교체 |
| 움직임이 끊김 | USB 허브 대역폭 | 허브 대신 PC 직결 |
| 서보 과열 경고 | 장시간 무거운 자세 유지 | 휴식 자세로 두고 냉각 |
