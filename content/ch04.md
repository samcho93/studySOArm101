## 작업 순서 한눈에

```text
1) 3D 프린팅         ─ 부품 출력
2) 서포트 제거        ─ 모든 구멍/홈 확인  ← 가장 많이 실수하는 단계
3) 서보 ID 설정       ─ 조립 전에! (5장)
4) 중립 위치 보정      ─ 조립 전에! (5장)
5) 관절 1~6 조립      ─ 이 장
6) 드라이버 보드 장착  ─ 이 장
7) 배선 및 전원        ─ 3장
```

:::warn 순서를 지키세요
**서보 ID 설정과 중위 캘리브레이션은 반드시 조립 전에** 해야 합니다. 조립 후에는 서보 하나만 버스에 연결하는 것이 불가능해져, ID를 다시 잡으려면 팔을 뜯어야 합니다.
:::

## 3D 프린팅

### 권장 출력 설정

| 항목 | 값 |
| --- | --- |
| 재료 | **PLA+** (PLA보다 인성이 높음) |
| 레이어 높이 | 0.4mm 노즐 → **0.2mm** / 0.6mm 노즐 → **0.4mm** |
| 인필 | **15%** |
| 서포트 | **Everywhere, 단 45° 이상 경사는 무시** |
| 베드 | 220×220mm (Ender 계열) 또는 205×250mm (Prusa/UP 계열) |

STL 파일은 [TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100) 저장소에 베드 크기별로 나뉘어 있습니다. 프린터가 없다면 출력 대행 서비스나 키트 벤더를 이용하세요.

### 출력 시 주의

- **ABS/PETG도 가능**하지만 수축률이 달라 나사 구멍 치수가 어긋날 수 있습니다. 처음이라면 PLA+로 시작하세요.
- 첫 레이어 접착이 중요한 긴 부품(upper arm, lower arm)은 **브림(brim)** 을 넣으면 휨을 줄일 수 있습니다.
- 실패 시 재출력 시간이 부품당 2~6시간이므로, **여분으로 그리퍼 조(jaw)와 모터 홀더는 한 벌 더** 뽑아 두면 마음이 편합니다.

## 서포트 제거 — 가장 중요한 준비 단계

원문 튜토리얼이 **"이 단계가 매우 중요하다"** 고 못 박는 부분입니다.

> 모든 구멍·홈·슬롯·격자를 하나하나 확인하세요. 특히 **주사위 5의 눈처럼 다섯 개의 원이 모여 있는 패턴**(원문은 마작패 "오통五筒"에 비유합니다)을 꼭 점검하세요.

서포트가 조금이라도 남아 있으면 **나중에 나사가 들어가지 않습니다.** 그 시점에는 이미 다른 부품이 조립되어 있어 되돌리기가 매우 번거롭습니다.

:::tip 제거 요령
작은 일자 드라이버를 서포트 아래로 밀어 넣어 들어 올리면 깔끔하게 떨어집니다. 마무리는 3mm 드릴비트나 줄로 구멍을 한 번씩 훑어 주세요.
:::

서포트 제거가 끝나면, **서보에 3핀 케이블을 미리 한 개씩 꽂아 두는 것**을 권장합니다. 조립 후에는 손이 들어가지 않는 위치가 생깁니다.

## 조립 전 준비물

| 항목 | 규격 | 용도 |
| --- | --- | --- |
| 나사 | **M2×6mm** | 서보를 프레임에 고정 (가장 작은 나사) |
| 나사 | **M3×6mm** | 구조물 간 결합, 서보 혼(horn) 고정 |
| 나사 | **M2.5×8mm** | 드라이버 보드 고정 |
| 스탠드오프 | M2.5 동봉 | 드라이버 보드 받침 |
| 공구 | 정밀 드라이버 세트 | — |

## 관절별 조립

각 관절은 **서보 혼(horn) 두 개를 먼저 설치**하는 공통 패턴을 따릅니다. 위쪽 혼은 **M3×6 나사로 고정**하고, 아래쪽 혼은 나사 없이 끼우기만 합니다.

### 관절 1 — 베이스 / 어깨 회전 (shoulder_pan)

1. 서보 혼 두 개 설치. 위쪽 혼은 M3×6으로 고정.
2. 1번 서보를 베이스에 넣습니다.
3. **M2×6 나사 4개**로 서보를 고정합니다. (위에서 2개, 아래에서 2개)
4. 첫 번째 모터 홀더를 밀어 넣고 **M2×6 나사 2개**(양쪽 하나씩)로 고정.
5. 어깨(shoulder) 부품을 붙입니다.
6. **M3×6 나사 4개를 위에, 4개를 아래에** 조여 어깨 부품을 고정.
7. 어깨 모터 홀더를 추가합니다.

### 관절 2 — 어깨 들기 (shoulder_lift)

1. 서보 혼 두 개 설치. 위쪽 혼은 M3×6으로 고정.
2. 2번 서보를 **위에서 아래로** 밀어 넣습니다.
3. **M2×6 나사 4개**로 고정.
4. 상완(upper arm)을 **양쪽에 M3×6 나사 4개씩** 으로 결합.

### 관절 3 — 팔꿈치 (elbow_flex)

1. 서보 혼 두 개 설치. 위쪽 혼은 M3×6으로 고정.
2. 3번 서보를 넣고 **M2×6 나사 4개**로 고정.
3. 전완(forearm)을 3번 서보에 **양쪽 M3×6 나사 4개씩** 으로 결합.

### 관절 4 — 손목 굽힘 (wrist_flex)

1. 서보 혼 두 개 설치. 위쪽 혼은 M3×6으로 고정.
2. 4번 모터 홀더를 밀어 끼웁니다.
3. 4번 서보를 밀어 넣습니다.
4. **M2×6 나사 4개**로 고정.

### 관절 5 — 손목 회전 (wrist_roll)

1. 5번 서보를 손목 홀더에 넣고 **앞쪽 M2×6 나사 2개**로 고정.
2. **손목 서보에는 혼을 하나만** 설치하고 M3×6 혼 나사로 고정합니다. (다른 관절과 다릅니다)
3. 손목을 4번 서보에 **양쪽 M3×6 나사 4개씩** 으로 고정.

### 관절 6 — 그리퍼 (팔로워) 또는 손잡이 (리더)

여기서부터 두 팔이 갈립니다.

**팔로워 — 그리퍼**

1. 그리퍼를 5번 서보에 붙이고, 손목의 서보 혼에 **M3×6 나사 4개**로 고정.
2. 그리퍼 서보를 넣고 **양쪽 M2×6 나사 2개씩** 으로 고정.
3. 그리퍼 서보에 혼 두 개 설치. 위쪽 혼은 M3×6으로 고정.
4. 그리퍼 조(claw)를 설치하고 **양쪽 M3×6 나사 4개씩** 으로 고정.

**리더 — 손잡이와 트리거**

1. 리더 홀더를 손목에 장착하고 **M3×6 나사 4개**로 고정.
2. 손잡이(handle)를 리더 홀더에 **M2×6 나사 1개**로 부착.
3. 그리퍼 서보를 넣고 양쪽 **M2×6 나사 2개씩**, 혼은 **M3×6 혼 나사**로 고정.
4. 팔로워 트리거를 **M3×6 나사 4개**로 부착.

:::tip 리더와 팔로워의 조립 차이
원문 튜토리얼 표현으로는 **"12단계까지는 완전히 동일하고, 그 이후 말단 장치(그리퍼 vs 손잡이)만 다르다"** 입니다. 두 팔을 동시에 조립하면 같은 단계를 두 번씩 하면 되니 효율적입니다.
:::

## 드라이버 보드 장착

1. **M2.5 동 스탠드오프 4개**를 베이스에 세웁니다.
2. **M2.5×8 나사 4개**로 서보 드라이버 보드를 고정합니다.
3. 보드를 팔 베이스에 장착하고 배선합니다.
4. ID=1인 첫 서보(shoulder_pan)의 3핀 케이블을 보드에 연결합니다.

## 조립 후 검수 체크리스트

:::check 전원을 넣기 전에 반드시 확인
- [ ] 모든 관절을 손으로 돌려봤을 때 **걸리는 구간 없이 부드러운가**? 뻑뻑하면 나사를 과도하게 조였거나 서포트가 남은 것입니다.
- [ ] 관절을 최대로 꺾었을 때 **3D 프린팅 부품끼리 부딪히지 않는가**?
- [ ] **케이블이 관절 사이에 끼이지 않는가**? 특히 손목 회전 시 케이블이 감기는지 확인.
- [ ] 서보 ID가 **1~6으로 중복 없이** 설정되어 있는가?
- [ ] 전원 어댑터가 **팔 종류와 맞는가**? (리더 5V 6A / 팔로워 12V 5A)
- [ ] 드라이버 보드 점퍼가 **B 채널(USB)** 에 있는가? (Waveshare 보드)
- [ ] 테이블 클램프로 **베이스가 단단히 고정**되어 있는가?
:::

:::danger 클램프는 필수입니다
팔로워 암은 고감속 서보의 토크가 강해서, 고정하지 않으면 팔이 움직일 때 **베이스가 통째로 넘어갑니다.** 테이블 클램프 2개로 반드시 고정하세요.
:::

## 자주 겪는 조립 문제

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 나사가 안 들어감 | 서포트 잔여물 | 드릴비트로 구멍 정리 |
| 관절이 뻑뻑함 | 나사 과조임 / 혼 정렬 불량 | 나사를 1/4바퀴 풀고 혼 위치 재확인 |
| 서보 혼이 헛돎 | 위쪽 혼 M3 나사 누락 | M3×6 혼 나사 체결 |
| 조립 후 한쪽 방향만 안 돎 | 중위 캘리브레이션 없이 조립 | 분해 후 5장 재수행 |
| 팔이 처짐 | 팔로워에 리더용 저감속 서보를 끼움 | 서보 모델 라벨(C001/C044/C046/C018) 재확인 |
| 통신은 되는데 안 움직임 | 외부 전원 미연결 | 어댑터 연결 확인 |
