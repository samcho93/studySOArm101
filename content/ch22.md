## 진단 순서 (막혔을 때)

:::tip 아래에서 위로 올라가며 확인하세요
1. **전원** — 어댑터가 꽂혀 있고 전압이 맞는가?
2. **케이블** — USB, 3핀 케이블이 모두 확실히 꽂혀 있는가?
3. **포트** — `ls /dev/ttyACM*` 로 장치가 보이는가?
4. **권한** — `groups` 에 `dialout`이 있는가?
5. **서보** — `scan_servos.py`로 6개가 다 응답하는가?
6. **캘리브레이션** — JSON 파일이 존재하고 범위가 정상인가?
7. **소프트웨어** — 가상환경이 활성화되어 있는가?

대부분의 문제는 1~4단계에서 해결됩니다.
:::

## 종합 프로젝트 — 큐브 픽앤플레이스

지금까지 배운 것을 전부 쓰는 최종 프로젝트입니다.

### 목표

> 테이블 위 임의의 위치에 놓인 4cm 검은 큐브를 집어, 지정된 상자에 넣는다.
> 성공률 **70% 이상**을 달성한다.

### 준비물

- SO-ARM101 리더 + 팔로워 1세트
- USB 웹캠 2대 (손목 + 전역)
- 4cm 큐브, 상자
- 테이블 클램프

---

### 단계 1 — 환경 구성 (30분)

:::task 체크리스트
- [ ] 팔로워를 테이블에 클램프로 고정
- [ ] 전역 카메라를 삼각대에 고정, 작업 공간 전체가 보이게 조정
- [ ] 손목 카메라 장착, 그리퍼 조가 프레임 하단에 살짝 보이게
- [ ] 큐브 배치 위치 5곳(A~E)을 테이프로 표시
- [ ] 조명 고정 (창가 피하기)
- [ ] `lerobot-find-port`로 포트 확인, udev 규칙 작성
- [ ] `lerobot-find-cameras opencv`로 카메라 인덱스 확인
:::

### 단계 2 — 캘리브레이션과 텔레오퍼레이션 검증 (20분)

```bash
lerobot-calibrate --robot.type=so101_follower \
  --robot.port=/dev/so101_follower --robot.id=proj_follower

lerobot-calibrate --teleop.type=so101_leader \
  --teleop.port=/dev/so101_leader --teleop.id=proj_leader

lerobot-teleoperate \
  --robot.type=so101_follower --robot.port=/dev/so101_follower --robot.id=proj_follower \
  --robot.cameras='{wrist: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30},
                    top:   {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30}}' \
  --teleop.type=so101_leader --teleop.port=/dev/so101_leader --teleop.id=proj_leader \
  --display_data=true
```

:::check 검증 포인트
- 리더를 움직이면 팔로워가 같은 방향으로 따라오는가?
- rerun 화면에서 두 카메라 영상이 모두 나오는가?
- **카메라 영상만 보고 큐브를 집을 수 있는가?** ← 가장 중요
:::

### 단계 3 — 데이터셋 수집 (60~90분)

위치당 10 에피소드씩, 총 50개를 목표로 합니다.

```bash
lerobot-record \
  --robot.type=so101_follower --robot.port=/dev/so101_follower --robot.id=proj_follower \
  --robot.cameras='{wrist: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30},
                    top:   {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30}}' \
  --teleop.type=so101_leader --teleop.port=/dev/so101_leader --teleop.id=proj_leader \
  --dataset.repo_id=myname/so101_cube_pick \
  --dataset.root=./datasets/so101_cube_pick \
  --dataset.push_to_hub=false \
  --dataset.no_stamp=true \
  --dataset.single_task="Pick the black cube and place it in the bin" \
  --dataset.num_episodes=50 \
  --dataset.fps=30 \
  --dataset.episode_time_s=20 \
  --dataset.reset_time_s=8 \
  --display_data=true
```

:::tip 수집 요령
- 큐브를 A→B→C→D→E 순환하며 배치합니다.
- **매번 같은 방식으로** 잡으세요 (같은 접근 방향, 같은 높이).
- 실패한 에피소드는 **즉시 `r` 키**로 다시 녹화합니다.
- 30분마다 쉬세요. 사람이 지치면 시연 품질이 떨어지고, 그게 그대로 데이터에 남습니다.
:::

### 단계 4 — 학습 (2~8시간)

```bash
lerobot-train \
  --dataset.repo_id=myname/so101_cube_pick \
  --dataset.root=./datasets/so101_cube_pick \
  --policy.type=act \
  --policy.device=cuda \
  --steps=60000 \
  --output_dir=outputs/train/act_cube_pick \
  --wandb.enable=true \
  --policy.push_to_hub=false
```

GPU가 없다면 [13장](~/lessons/ch13.html)의 Colab 또는 HF Jobs 경로를 쓰세요.

### 단계 5 — 평가 (30분)

```bash
lerobot-rollout \
  --strategy.type=episodic \
  --policy.path=outputs/train/act_cube_pick/checkpoints/last/pretrained_model \
  --robot.type=so101_follower --robot.port=/dev/so101_follower --robot.id=proj_follower \
  --robot.cameras='{wrist: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30},
                    top:   {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30}}' \
  --dataset.repo_id=myname/rollout_cube_pick \
  --dataset.root=./datasets/rollout_cube_pick \
  --dataset.no_stamp=true \
  --dataset.push_to_hub=false \
  --dataset.single_task="Pick the black cube and place it in the bin" \
  --dataset.num_episodes=20
```

결과를 기록합니다.

| 위치 | 시도 | 성공 | 실패 양상 |
| --- | --- | --- | --- |
| A | 4 | | |
| B | 4 | | |
| C | 4 | | |
| D | 4 | | |
| E | 4 | | |
| **합계** | **20** | | **성공률 __%** |

### 단계 6 — 개선 루프

성공률이 70% 미만이라면 [14장](~/lessons/ch14.html)의 실패 분석표를 참고해 가장 많이 실패한 패턴부터 데이터를 보강합니다.

```bash
lerobot-record \
  ... \
  --dataset.root=./datasets/so101_cube_pick \
  --dataset.repo_id=myname/so101_cube_pick \
  --resume=true \
  --dataset.num_episodes=15
```

재학습 후 다시 평가합니다. 보통 **2~3회 루프**면 70%를 넘깁니다.

## 심화 과제

기본 프로젝트를 끝냈다면 다음을 시도해 보세요.

| 과제 | 난이도 | 배우는 것 |
| --- | --- | --- |
| 여러 색 큐브 중 특정 색만 집기 | ★★ | 시각적 구분, SmolVLA의 언어 조건부 |
| 큐브 2개를 쌓기 | ★★★ | 순차 작업, 정밀 배치 |
| 컵에 물체 넣기 | ★★★ | 좁은 목표, 정밀 삽입 |
| MoveIt으로 접근 + 정책으로 파지 | ★★★★ | 하이브리드 제어 ([20장](~/lessons/ch20.html)) |
| 장애물 사이로 경로 계획 | ★★★ | MoveIt Scene Objects ([18장](~/lessons/ch18.html)) |
| Gazebo에서 먼저 검증 후 실기 | ★★★ | Sim2Real 파이프라인 ([19장](~/lessons/ch19.html)) |
| 듀얼 암으로 물건 건네주기 | ★★★★★ | 양손 협조 ([21장](~/lessons/ch21.html)) |
