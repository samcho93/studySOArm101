## 왜 헷갈리는가

리더와 팔로워를 모두 꽂으면 PC에는 **똑같이 생긴 시리얼 포트 두 개**가 생깁니다. 어느 쪽이 리더이고 어느 쪽이 팔로워인지 알아야 모든 명령이 제대로 동작합니다.

게다가 이 포트 번호는 **꽂는 순서에 따라 바뀔 수 있습니다.** 재부팅하거나 USB를 다시 꽂으면 리더와 팔로워가 뒤바뀔 수 있다는 뜻입니다.

---

## 방법 1 — OS 명령으로 직접 보기

### Linux (Ubuntu)

```bash
ls /dev/ttyACM*
```

USB를 꽂기 **전후로 두 번** 실행해 새로 생긴 장치를 확인하는 것이 가장 확실합니다.

:::tip 꽂는 순서를 정해 두세요
원문 튜토리얼의 권장 순서는 **팔로워(Follower)를 먼저 꽂고, 그다음 리더(Leader)를 꽂는** 것입니다. 이러면 일반적으로 이렇게 잡힙니다.

- `/dev/ttyACM0` → **팔로워(종동팔)**
- `/dev/ttyACM1` → **리더(주동팔)**
:::

### Windows

**장치 관리자 → 포트(COM & LPT)** 에서 `COM3`, `COM4` 같은 번호를 확인합니다. USB를 뺐다 꽂으며 어느 번호가 사라졌다 나타나는지 보면 구분됩니다.

---

## 방법 2 — LeRobot 공식 도구 (권장)

```bash
lerobot-find-port
```

실행하면 현재 포트 목록을 보여주고, **USB 케이블을 뽑으라고 안내**합니다. 뽑고 Enter를 누르면 사라진 포트를 찾아 알려줍니다.

```text
Finding all available ports for the MotorBus.
['/dev/ttyACM0', '/dev/ttyACM1']
Remove the usb cable from your MotorsBus and press Enter when done.

[...해당하는 리더 또는 팔로워 팔의 USB를 뽑고 Enter...]

The port of this MotorsBus is /dev/ttyACM1
Reconnect the USB cable.
```

:::warn 반드시 USB를 실제로 뽑아야 합니다
케이블을 뽑지 않으면 포트가 감지되지 않습니다. 전원 어댑터가 아니라 **USB 커넥터**를 뽑아야 합니다.
:::

**리더와 팔로워 각각 한 번씩, 총 두 번** 실행하세요.

## 내 포트 기록해 두기

앞으로 모든 명령에 이 값을 넣게 됩니다. 메모해 두세요.

| 역할 | 내 포트 | LeRobot 타입 | id 이름(예시) |
| --- | --- | --- | --- |
| 팔로워 (종동팔) | `/dev/ttyACM0` | `so101_follower` | `my_awesome_follower_arm` |
| 리더 (주동팔) | `/dev/ttyACM1` | `so101_leader` | `my_awesome_leader_arm` |

:::tip 명령어 생성기를 쓰세요
[명령어 생성기](~/tools/cli-builder.html)에 포트와 id를 한 번 입력해 두면, 이후 모든 장의 명령이 **내 환경에 맞게 자동 완성**됩니다. 브라우저에 저장되므로 다시 입력할 필요가 없습니다.
:::

## 포트 권한 설정

### 임시 — 재부팅하면 초기화됨

Linux:

```bash
sudo chmod 666 /dev/ttyACM0
sudo chmod 666 /dev/ttyACM1
```

한 번에:

```bash
sudo chmod 666 /dev/ttyACM*
```

### 영구 — dialout 그룹 (권장)

```bash
sudo usermod -a -G dialout $USER
```

:::warn 로그아웃 후 다시 로그인해야 적용됩니다
그룹 변경은 새 로그인 세션부터 반영됩니다. `groups` 명령으로 `dialout`이 보이면 성공입니다.
:::

### 권한 오류 증상

```text
serial.serialutil.SerialException: [Errno 13] could not open port /dev/ttyACM0:
[Errno 13] Permission denied: '/dev/ttyACM0'
```

이 오류가 뜨면 위 권한 설정을 하지 않은 것입니다.

## udev 규칙으로 포트 고정 (강력 추천)

포트 번호가 매번 바뀌는 문제를 근본적으로 해결하는 방법입니다. **USB 장치의 시리얼 번호에 고정된 이름을 붙입니다.**

### 1. 장치 정보 확인

```bash
udevadm info -a -n /dev/ttyACM0 | grep -E 'ATTRS\{(idVendor|idProduct|serial)\}' | head -3
```

출력 예:

```text
ATTRS{idVendor}=="1a86"
ATTRS{idProduct}=="55d3"
ATTRS{serial}=="5AAF2193061"
```

### 2. 규칙 파일 작성

```bash
sudo nano /etc/udev/rules.d/99-so-arm101.rules
```

```text
# SO-ARM101 팔로워(종동팔)
SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{serial}=="5AAF2193061", SYMLINK+="so101_follower", MODE="0666"

# SO-ARM101 리더(주동팔)
SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{serial}=="5AAF2194741", SYMLINK+="so101_leader", MODE="0666"
```

### 3. 적용

```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
```

USB를 다시 꽂으면 이제 다음 이름으로 항상 접근할 수 있습니다.

```bash
ls -l /dev/so101_*
```

```text
/dev/so101_follower -> ttyACM0
/dev/so101_leader   -> ttyACM1
```

이제 명령에서 이렇게 쓰면 됩니다.

```bash
--robot.port=/dev/so101_follower
--teleop.port=/dev/so101_leader
```

:::tip 듀얼 암이라면 필수입니다
[21장](~/lessons/ch21.html)의 듀얼 팔로워 구성에서는 포트가 4개가 되어 뒤섞이기 매우 쉽습니다. udev 규칙을 미리 만들어 두면 "왼팔과 오른팔이 뒤바뀌는" 사고를 막을 수 있습니다.
:::

## 연결 검증

포트가 제대로 잡혔는지 확인하는 가장 빠른 방법은 서보 스캔입니다.

```bash
python scripts/scan_servos.py --port /dev/ttyACM0
```

정상이라면 ID 1~6이 모두 응답합니다.

```text
포트 /dev/ttyACM0 (1000000 bps) 스캔 중...
  ID 1  shoulder_pan    위치 2041  (-0.6°)   전압 11.9V  온도 31°C
  ID 2  shoulder_lift   위치 2050  ( 0.2°)   전압 11.9V  온도 30°C
  ID 3  elbow_flex      위치 2047  (-0.1°)   전압 11.9V  온도 32°C
  ID 4  wrist_flex      위치 2048  ( 0.0°)   전압 11.9V  온도 29°C
  ID 5  wrist_roll      위치 2045  (-0.3°)   전압 11.9V  온도 30°C
  ID 6  gripper         위치 2100  ( 4.6°)   전압 11.9V  온도 28°C
6개 서보 발견.
```

| 스캔 결과 | 의미 |
| --- | --- |
| 6개 모두 발견 | 정상 |
| 0개 발견 | 포트가 틀렸거나, 전원 미연결, 또는 Waveshare 점퍼가 A 채널 |
| 일부만 발견 | 해당 서보의 3핀 케이블 접촉 불량 또는 ID 미설정 |
| ID 1이 여러 개 | ID 설정이 안 된 서보가 섞임 → [5장](~/lessons/ch05.html) 재수행 |
