01SO-ARM101이란 무엇인가

LeRobot 생태계와 SO-ARM101의 위치, 이 강좌에서 무엇을 만들게 되는지 로드맵을 잡습니다.

시뮬레이터 열기 URDF 뷰어 명령어 생성기

한 줄 요약#

SO-ARM101은 Hugging Face의 로봇 학습 프레임워크 LeRobot 팀이 TheRobotStudio와 함께 설계한, 3D 프린팅 구조물 + 피드백 버스 서보로 만드는 6자유도 오픈소스 로봇팔입니다. 팔로워 1대 기준 부품값이 $122 수준이라 "학생도 살 수 있는 실체형 로봇(embodied AI body)"이라 불립니다.

이 강좌의 목표

실물이 없어도 브라우저 3D 시뮬레이터로 기구학·텔레오퍼레이션·궤적 녹화를 먼저 체험하고, 실물이 도착하면 조립 → 캘리브레이션 → 데이터 수집 → 정책 학습 → ROS 2 연동까지 끊김 없이 이어갈 수 있게 하는 것.

체화된 지능(Embodied AI)과 LeRobot#

체화된 지능이란#

중국어 원문의 具身智能, 영어로는 Embodied AI, 한국어로는 보통 체화된 지능 또는 신체화 지능이라고 옮깁니다. 말 그대로 몸을 가진 지능입니다. AI를 실제 하드웨어에 연결해 물리 세계에서 행동하게 만드는 분야로, 4족 로봇개, 2족 휴머노이드, 휠-레그 로봇, 드론, 자율주행차가 모두 여기에 속합니다. 로봇팔은 그중 가장 싸게, 가장 빨리 손에 넣을 수 있는 입문용 몸체입니다.

LeRobot이란#

LeRobot은 Hugging Face가 공개한 로봇 AI(체화 지능) 소프트웨어 프레임워크입니다.

  • 저장소: github.com/huggingface/lerobot
  • PyTorch 기반. 강화학습과 모방학습(VLA) 의 데이터 수집 → 알고리즘 학습 → 추론 배포 전 과정을 낮은 진입장벽으로 제공합니다.
  • 지원 로봇 범위가 넓습니다. 수십만 원대 SO-ARM101·LeKiwi 소형 카트부터, 수백만 원대 산업용 팔(AgileX Piper, StarAI), Hope-JR 다지 손, 천만 원대 Unitree G1 휴머노이드까지. 사실상 업계 데이터 수집·학습의 사실상 표준(de facto standard) 이 되었습니다.
  • 자신의 로봇을 LeRobot 규격에 맞춰 적응시키는 것도 가능합니다.

LeRobot 데이터셋과 모델#

LeRobot은 자체 모방학습 데이터셋 포맷(LeRobotDataset)을 정의합니다. Hugging Face Hub에 공개된 모든 데이터셋·모델을 열람·다운로드·학습에 사용할 수 있고, 내가 만든 데이터셋을 업로드해 공유할 수도 있습니다.

모방학습과 VLA#

사람이 로봇팔을 직접 끌어서(시연, demonstration) 동작을 보여주면, 그 궤적과 카메라 영상이 데이터셋이 됩니다. 이 데이터셋으로 모방학습 알고리즘을 학습시키고 로봇에 배포하면, 로봇은 원격조작 없이 스스로 그 동작을 재현하고 새로운 상황에도 일반화합니다.

원문 튜토리얼의 예시처럼 "가재를 집어 → 양념에 찍고 → 기름솥에 넣는" 동작을 50회 시연으로 학습시키면, 처음 보는 가재가 와도 로봇이 즉시 반응해 작업을 완수합니다.

모방학습은 요즘 VLA(Vision-Language-Action, 시각-언어-행동 대형 모델) 라는 이름으로도 불립니다. 체화 지능 분야에서 가장 빠르게 발전하고, 투자가 몰리고, 오픈소스 생태계가 활발한 영역입니다.

LeRobot이 주로 지원하는 모방학습 알고리즘:

알고리즘특징이 강좌에서
ACT (Action Chunking Transformer)가볍고 학습이 빠름. SO-ARM101의 사실상 기본값13장 주력
Diffusion Policy다봉(multimodal) 분포에 강함. 데이터가 많을 때 유리13장 비교
SmolVLA소형 VLA. 언어 지시 + 시각 입력13장 비교
π0 / π0.5 (Pi0)대형 VLA. 프리트레인 기반 범용성13장 소개
Wall-OSS오픈소스 VLA 계열참고

SO-ARM101 한눈에 보기#

SO-ARM101은 리더 암(Leader) 과 팔로워 암(Follower) 두 대가 한 세트입니다. 중국어 원문에서는 각각 주동팔(主动臂), 종동팔(从动臂) 이라고 부릅니다.

  • 리더 암: 사람이 손으로 잡고 움직이는 쪽. 손잡이와 트리거가 달려 있습니다. 힘을 적게 들여 움직일 수 있도록 감속비가 낮은 서보를 씁니다.
  • 팔로워 암: 실제로 물건을 집는 쪽. 끝에 그리퍼(집게)가 달려 있고, 자기 무게와 부하를 버티도록 감속비가 높은 고토크 서보를 씁니다.

두 팔 모두 5자유도 + 그리퍼 1자유도 구성입니다. (본 강좌와 URDF에서는 그리퍼를 포함해 6개 조인트로 다룹니다.)

왜 "101"인가

전작 SO-100의 개선판입니다. 배선이 정리되었고, 조립 시 기어를 빼낼 필요가 없어졌으며, 리더 암의 서보가 감속비별로 최적화되었습니다. SO-100은 현재 deprecated 상태이므로 새로 시작한다면 무조건 101입니다.

필요한 PC 사양#

환경가능한 작업
일반 Windows 노트북학습(training) 직전까지 모든 작업 — 조립, 캘리브레이션, 텔레오퍼레이션, 데이터 수집
NVIDIA GPU 탑재 Ubuntu PC모든 작업 — 실기 제어 + ACT/VLA 학습 + ROS 2 / Gazebo
GPU가 없어도 됩니다

학습은 Google Colab, Hugging Face Jobs, 또는 국내 클라우드 GPU에서 돌릴 수 있습니다. 실제로 이 강좌의 13장은 로컬 GPU가 없는 경우의 학습 경로를 따로 다룹니다.

ROS 2 파트(15~20장)는 Ubuntu 22.04 + ROS 2 Humble 또는 Ubuntu 24.04 + ROS 2 Jazzy를 권장합니다. Windows 사용자는 WSL2에 Ubuntu를 올려 진행하면 됩니다.

이 강좌의 구성#

이 강좌는 钜犀科技(Juxi Tech, 쥐시테크)의 SO-ARM101机械臂教程 위키 목차를 한국어로 재구성하고, LeRobot 공식 문서·TheRobotStudio 저장소·ROS 2 생태계 자료를 추가해 만들었습니다.

강좌에 포함된 도구#

  • 3D 시뮬레이터 — URDF에서 추출한 실제 기구학으로 움직입니다. 조인트 슬라이더, IK 타깃 드래그, 리더→팔로워 텔레오퍼레이션, 궤적 녹화/재생, 손목 카메라 뷰, joint_states JSON 출력까지 지원합니다.
  • 명령어 생성기 — 내 포트/ID/카메라 설정을 입력하면 lerobot-* 명령을 완성해 줍니다. 오타로 인한 시행착오를 없애줍니다.
  • **ros2_ws/** — 바로 colcon build 가능한 ROS 2 패키지 스켈레톤(description / bringup / moveit_config).
  • **scripts/** — 파이썬 실습 예제(FK·IK 계산, 키보드 텔레오퍼레이션, LeRobot↔ROS 2 브릿지).
