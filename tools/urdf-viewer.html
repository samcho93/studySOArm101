1. 바로 보기

강좌에 들어 있는 기구학 값으로 URDF를 즉석에서 만들어 띄웁니다. 인터넷도 파일도 필요 없지만, 형상은 상자로 근사한 것입니다.

2. 저장소에서 받아 보기

TheRobotStudio 저장소의 URDF를 그대로 받아옵니다. 진짜 STL 메시까지 그려집니다.

메시는 URDF 주소를 기준으로 상대 경로를 따라갑니다. 서버가 CORS를 막아 두면 실패하며, 그때는 아래 3번을 쓰세요.

3. 내 컴퓨터에서 열기

저장소를 clone 했다면 Simulation/SO101 폴더를 통째로 고르세요. URDF와 assets/ 안의 STL을 함께 읽습니다. 3D 화면에 끌어다 놓아도 됩니다.

조인트 값

슬라이더 범위는 URDF에 적힌 한계 그대로입니다. 행에 마우스를 올리면 그 조인트가 움직이는 링크가 3D 화면에서 밝아집니다.

링크 트리

    조인트 표

    이 페이지가 하는 일

    URDF 파일을 직접 파싱해 링크 트리를 만들고, 각 링크의 <visual>·<collision> 형상을 그립니다. STL은 바이너리·ASCII 둘 다 읽습니다. rerun의 URDF visualizer가 하는 일과 같지만, 여기서는 조인트를 직접 움직여 볼 수 있습니다.

    화면 조작

    • 드래그 — 시점 회전
    • 휠 — 확대 / 축소
    • Shift + 드래그 — 시점 이동
    • 우측 상단 ⛶ — 모델이 화면에 꽉 차도록 맞추기

    무엇을 확인하게 되나

    • 메시 경로 — 빨간 경고가 뜨면 filename이 실제 파일과 어긋난 것입니다
    • 축 방향 — "링크 좌표계"를 켜면 각 링크의 x(빨강)·y(초록)·z(파랑)가 보입니다
    • 충돌 형상 — visual을 끄고 collision만 켜면 실제로 충돌 검사에 쓰이는 모양이 드러납니다. SO-101 URDF는 베이스에도 충돌 메시가 있고, MJCF에는 없습니다 (15장)
    • 조인트 한계 — 슬라이더 양 끝이 URDF의 lower/upper입니다
