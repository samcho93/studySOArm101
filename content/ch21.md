## 듀얼 팔로워 구성

한 팔로는 못 하는 작업이 많습니다. "왼손으로 물건을 집어 오른손에 건네기", "한 손으로 잡고 다른 손으로 조작하기" 같은 양손 협조 작업입니다.

SO-ARM101 듀얼 구성은 **리더 2대 + 팔로워 2대**, 총 4개의 팔입니다.

### 배선표

| 역할 | 포트 |
| --- | --- |
| 왼쪽 팔로워 | `/dev/ttyACM0` |
| 오른쪽 팔로워 | `/dev/ttyACM1` |
| 왼쪽 리더 | `/dev/ttyACM2` |
| 오른쪽 리더 | `/dev/ttyACM3` |

팔로워 타입은 `so101_follower`, 리더 타입은 `so101_leader`입니다. (LeRobot에서 `so100_leader`와 `so101_leader`는 같은 구현을 공유합니다.)

:::danger 포트 4개는 반드시 udev로 고정하세요
포트 번호가 섞이면 왼팔·오른팔이 뒤바뀌어 위험합니다. [7장](~/lessons/ch07.html)의 udev 규칙으로 `/dev/so101_follower_left` 같은 고정 이름을 만드세요.
:::

### USB 권한

```bash
sudo chmod 666 /dev/ttyACM0 /dev/ttyACM1 /dev/ttyACM2 /dev/ttyACM3
```

## 듀얼 암 캘리브레이션

각 팔을 **개별적으로** 캘리브레이션합니다. 이름 규칙이 중요합니다.

```bash
# 왼쪽 팔로워
lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_so101_bi_follower_left

# 오른쪽 팔로워
lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM1 \
    --robot.id=my_so101_bi_follower_right

# 왼쪽 리더
lerobot-calibrate \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM2 \
    --teleop.id=my_so101_bi_leader_left

# 오른쪽 리더
lerobot-calibrate \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM3 \
    --teleop.id=my_so101_bi_leader_right
```

캘리브레이션 파일 위치:

```text
~/.cache/huggingface/lerobot/calibration/robots/so_follower/my_so101_bi_follower_left.json
~/.cache/huggingface/lerobot/calibration/robots/so_follower/my_so101_bi_follower_right.json
~/.cache/huggingface/lerobot/calibration/teleoperators/so_leader/my_so101_bi_leader_left.json
~/.cache/huggingface/lerobot/calibration/teleoperators/so_leader/my_so101_bi_leader_right.json
```

:::warn `_left` / `_right` 접미사가 필수입니다
`bi_so_follower` 타입은 `<id>_left` / `<id>_right` 형태의 캘리브레이션 파일을 찾습니다. 이 규칙을 지키지 않으면 텔레오퍼레이션 시 **다시 캘리브레이션하라는 안내**가 반복됩니다.
:::

### 기존 캘리브레이션 재활용

이전에 다른 id로 캘리브레이션했다면 파일을 복사하면 됩니다.

```bash
CAL_DIR=~/.cache/huggingface/lerobot/calibration

cp $CAL_DIR/robots/so_follower/my_awesome_follower_arm1.json \
   $CAL_DIR/robots/so_follower/my_so101_bi_follower_left.json
cp $CAL_DIR/robots/so_follower/my_awesome_follower_arm2.json \
   $CAL_DIR/robots/so_follower/my_so101_bi_follower_right.json
cp $CAL_DIR/teleoperators/so_leader/my_awesome_leader_arm3.json \
   $CAL_DIR/teleoperators/so_leader/my_so101_bi_leader_left.json
cp $CAL_DIR/teleoperators/so_leader/my_awesome_leader_arm4.json \
   $CAL_DIR/teleoperators/so_leader/my_so101_bi_leader_right.json
```

## 듀얼 암 텔레오퍼레이션

### 카메라 없이

```bash
lerobot-teleoperate \
    --robot.type=bi_so_follower \
    --robot.left_arm_config.port=/dev/ttyACM0 \
    --robot.right_arm_config.port=/dev/ttyACM1 \
    --robot.id=my_so101_bi_follower \
    --teleop.type=bi_so_leader \
    --teleop.left_arm_config.port=/dev/ttyACM2 \
    --teleop.right_arm_config.port=/dev/ttyACM3 \
    --teleop.id=my_so101_bi_leader \
    --display_data=true
```

### 카메라 포함

카메라 인덱스는 `lerobot-find-cameras opencv`로 확인합니다.

```bash
lerobot-teleoperate \
    --robot.type=bi_so_follower \
    --robot.left_arm_config.port=/dev/ttyACM0 \
    --robot.left_arm_config.cameras='{
      left_wrist: {"type": "opencv", "index_or_path": 2, "width": 640, "height": 480, "fps": 30}
    }' \
    --robot.right_arm_config.port=/dev/ttyACM1 \
    --robot.right_arm_config.cameras='{
      right_wrist: {"type": "opencv", "index_or_path": 4, "width": 640, "height": 480, "fps": 30}
    }' \
    --robot.id=my_so101_bi_follower \
    --teleop.type=bi_so_leader \
    --teleop.left_arm_config.port=/dev/ttyACM2 \
    --teleop.right_arm_config.port=/dev/ttyACM3 \
    --teleop.id=my_so101_bi_leader \
    --display_data=true
```

:::danger 두 팔이 서로 부딪힙니다
듀얼 암에서 가장 흔한 사고는 **두 팔로워가 충돌**하는 것입니다. LeRobot 텔레오퍼레이션에는 팔 간 충돌 검사가 없습니다.

- 두 팔의 작업영역이 겹치는 범위를 미리 파악하세요.
- 처음에는 **간격을 넉넉히** 두고 배치하세요.
- 충돌 회피가 꼭 필요하면 MoveIt 2의 다중 그룹 플래닝을 쓰세요. ([18장](~/lessons/ch18.html))
:::

## 듀얼 암 데이터셋 수집

```bash
lerobot-record \
    --robot.type=bi_so_follower \
    --robot.left_arm_config.port=/dev/ttyACM0 \
    --robot.right_arm_config.port=/dev/ttyACM1 \
    --robot.id=my_so101_bi_follower \
    --teleop.type=bi_so_leader \
    --teleop.left_arm_config.port=/dev/ttyACM2 \
    --teleop.right_arm_config.port=/dev/ttyACM3 \
    --teleop.id=my_so101_bi_leader \
    --dataset.repo_id=myname/bi_so101_task \
    --dataset.root=./datasets/bi_so101_task \
    --dataset.push_to_hub=false \
    --dataset.no_stamp=true \
    --dataset.single_task="Pick the cube with left arm and hand it to right arm" \
    --dataset.num_episodes=50 \
    --dataset.fps=30 \
    --dataset.episode_time_s=30 \
    --dataset.reset_time_s=10 \
    --dataset.video=true
```

:::info 영상 코덱
기본 코덱은 이미 `libsvtav1`이므로 따로 지정할 필요가 없습니다. 바꾸려면 중첩 파라미터를 쓰세요.
```bash
--dataset.rgb_encoder.vcodec=h264
```
(구버전의 `--dataset.vcodec=...` 은 더 이상 존재하지 않습니다.)
:::

### 이어 녹화

```bash
lerobot-record \
    ... \
    --dataset.repo_id=myname/bi_so101_task \
    --dataset.root=./datasets/bi_so101_task \
    --resume=true \
    --dataset.num_episodes=35
```

[11장](~/lessons/ch11.html)의 resume 주의사항이 그대로 적용됩니다.

### 학습

```bash
lerobot-train \
    --dataset.repo_id=myname/bi_so101_task \
    --dataset.root=./datasets/bi_so101_task \
    --policy.type=act \
    --policy.device=cuda \
    --steps=60000 \
    --output_dir=outputs/train/act_bi_so101 \
    --wandb.enable=false \
    --policy.push_to_hub=false
```

:::tip 듀얼 암은 데이터가 더 필요합니다
행동 차원이 두 배(12차원)이고 협조 작업은 더 복잡합니다. 단일 팔에서 50개면 되던 작업이 듀얼에서는 **100~150개**를 요구하는 경우가 많습니다. 학습 스텝도 100,000까지 늘려 보세요.
:::

### 배포

```bash
lerobot-rollout \
    --strategy.type=episodic \
    --policy.path=outputs/train/act_bi_so101/checkpoints/last/pretrained_model \
    --robot.type=bi_so_follower \
    --robot.left_arm_config.port=/dev/ttyACM0 \
    --robot.right_arm_config.port=/dev/ttyACM1 \
    --robot.id=my_so101_bi_follower \
    --dataset.repo_id=myname/rollout_bi_so101_task \
    --dataset.root=./datasets/rollout_bi_so101_task \
    --dataset.num_episodes=10
```

## 듀얼 암 문제 해결

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| 텔레오퍼레이션 시 재캘리브레이션 요구 | `_left`/`_right` 접미사 없는 캘리브레이션 파일 | 접미사 포함 id로 재캘리브레이션 또는 파일 복사 |
| 리더가 손으로 안 움직임 | 리더 토크가 꺼지지 않음 | 재캘리브레이션 또는 서보 점검 |
| 이어 녹화 시 "디렉터리 존재" 오류 | `--resume=true` 누락 | 추가 |
| resume 시 root 요구 오류 | 데이터셋 디렉터리 미지정 | `--dataset.root=` 를 첫 녹화와 동일하게 |
| 디렉터리에 타임스탬프가 붙음 | `no_stamp` 미설정 | `--dataset.no_stamp=true` |
| `--dataset.vcodec` 인자 없음 | 구버전 파라미터 | `--dataset.rgb_encoder.vcodec=h264` |
| 배포 시 `--policy.path` / `eval_` 오류 | `lerobot-record`로 배포 시도 | `lerobot-rollout --strategy.type=episodic`, 데이터셋명 `rollout_` 시작 |
| 좌우가 바뀜 | 포트 설정 오류 | `left_arm_config.port` ↔ `right_arm_config.port` 교체 |
| 학습 시 데이터셋 못 찾음 | 로컬 데이터셋에 root 미지정 | `--dataset.root=./datasets/xxx` |
| 데이터셋이 자동 업로드됨 | `push_to_hub` 기본값 true | `--dataset.push_to_hub=false` |
| 종료 시 `You must add one or several frames...` | reset 단계에서 종료 | 기록된 데이터엔 영향 없음. `--resume=true`로 계속 |

## 모바일 플랫폼 — LeKiwi와 XLeRobot

팔이 고정되어 있으면 작업 반경이 최대 48cm, 실용 구간은 30cm 안쪽입니다. 바퀴를 달면 방 전체가 작업영역이 됩니다.

### LeKiwi

SO-ARM101을 **3륜 옴니휠 모바일 베이스**에 올린 구성입니다.

- 라즈베리파이가 로봇에 탑재되고, PC와 무선으로 통신합니다.
- LeRobot에 `lekiwi` 타입으로 통합되어 있어 텔레오퍼레이션·녹화·학습 흐름이 동일합니다.
- 행동 공간에 **베이스 이동(x, y, θ)** 이 추가됩니다.

### XLeRobot

**듀얼 SO-ARM101 + 모바일 베이스** 구성입니다. 총 비용 약 $660 수준으로, 양손 모바일 조작(mobile manipulation) 연구를 저비용으로 할 수 있습니다.

:::info 원문 위키에도 항목이 있습니다
Juxi 위키에는 `Lekiwi移动机器人使用教程`(레키위 모바일 로봇 사용 튜토리얼)와 `Xlerobot` 항목이 별도로 존재합니다. 하드웨어 구성과 배선이 다르므로 해당 문서를 참고하세요.
:::

## 다지 손 — AmazingHand

2지 그리퍼로는 못 하는 작업이 있습니다. **AmazingHand**는 SO-ARM101 손목에 장착하는 오픈소스 다관절 손입니다.

- 장착 시 행동 차원이 크게 늘어납니다 (손가락 관절 수만큼).
- 데이터 수집 난이도가 올라갑니다. 리더 암만으로는 손가락을 제어할 수 없어, 별도의 입력 장치(글러브, 원격조작 손)가 필요합니다.
- 원문 위키에 `AmazingHand灵巧手使用教程`(AmazingHand 다지 손 사용 튜토리얼)와 `SO-ARM101&AmazingHand使用教程` 항목이 있습니다.

## 7축 변형

기본 SO-ARM101은 5자유도라 **위치와 방향을 동시에 완전히 만족시킬 수 없습니다**([2장](~/lessons/ch02.html)). 관절을 추가하면 이 제약이 풀립니다.

- 원문 위키의 `SO-ARM101机械臂 7轴 教程`(SO-ARM101 7축 튜토리얼) 참고.
- ROS 2 쪽에서는 `elbow_rotate` 조인트를 전완과 손목 사이에 추가해 **6자유도 데카르트 자세 계획**을 가능하게 한 커뮤니티 구현도 있습니다.

:::warn 축을 추가하면 모든 것이 바뀝니다
URDF, SRDF, ros2_control 설정, LeRobot 로봇 타입 정의, 기존 데이터셋 호환성이 전부 영향을 받습니다. 기존 데이터셋으로 학습한 정책은 **사용할 수 없습니다.**
:::

## 그 밖의 확장 모듈

원문 위키에 별도 튜토리얼이 있는 주변 모듈들입니다.

| 모듈 | 용도 |
| --- | --- |
| **RealSense D405 / D435i** | 깊이 카메라. 정밀 파지 연구 |
| **IMU 모듈** | 자세 추정 |
| **CSI 카메라** | 라즈베리파이/Jetson용 저지연 카메라 |
| **OLED 부화면** | 상태 표시 |
| **KWS 음성인식 사운드카드** | 음성 명령 |
| **AI 음성 대화 모듈** | 자연어 인터페이스 |
| **2자유도 서보 짐벌** | 전역 카메라 능동 제어 |
| **ESP32 영상전송 모듈** | 무선 카메라 |
| **ESP32-S3 무선 텔레오퍼레이션** | 케이블 없는 리더 암 |
| **MAX30102 심박·산소 센서** | 생체 신호 실험 |
| **Jetson Orin Nano/NX** | 엣지 추론 플랫폼 |
| **KVM 스위치 / HDMI 캡처** | 다중 장비 개발 환경 |
