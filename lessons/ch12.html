12시뮬레이션 데이터 수집 (LeIsaac)

Isaac Lab 기반 LeIsaac으로 가상 환경에서 원격조작 데이터를 모으고 LeRobot 포맷으로 변환합니다.

시뮬레이터 열기 URDF 뷰어 명령어 생성기

왜 시뮬레이션인가#

실기 데이터 수집은 정직하지만 느립니다. 에피소드 하나에 30초, 50개면 리셋 시간까지 합쳐 약 1시간. 물체를 매번 제자리에 갖다 놓는 것도 사람 몫입니다.

시뮬레이션은 이 병목을 깨줍니다.

항목실기시뮬레이션
리셋사람이 손으로자동, 즉시
병렬 수집불가수십 개 환경 동시
물체 다양성실제로 사야 함에셋 교체로 무한
도메인 격차없음있음 (Sim2Real gap)
파손 위험있음없음
현실적인 사용법

시뮬레이션만으로 실기 성능을 내기는 어렵습니다. 보통 시뮬레이션으로 대량 사전학습 → 실기 데이터 소량으로 파인튜닝 하는 방식을 씁니다.

LeIsaac이란#

LeIsaac은 光轮智能(LightwheelAI, 라이트휠 AI)이 만든 도구로, NVIDIA Isaac Lab 안에서 SO101Leader(LeRobot 리더 암) 로 원격조작을 수행하고, 데이터 수집 → 변환 → 정책 학습까지 이어주는 프레임워크입니다.

  • 저장소: github.com/LightwheelAI/leisaac
  • 문서: lightwheelai.github.io/leisaac

핵심 기능#

  • Isaac Lab 안에서 SO101Follower를 로봇으로 사용하고, 여기에 맞는 원격조작 방식을 제공합니다.
  • 수집한 HDF5 데이터를 LeRobot Dataset 포맷으로 변환하는 스크립트를 제공합니다.
  • 시뮬레이션에서 모은 데이터로 GR00T N1.5 등을 파인튜닝해 실기에 배포하는 경로를 지원합니다.
  • datagen 모듈로 모션 궤적을 프로그래밍 방식으로 생성할 수 있습니다.
  • 원격 텔레오퍼레이션(다른 PC에서 조작) 을 지원합니다.

시스템 요구사항#

하드웨어 장벽이 있습니다

Isaac Lab은 NVIDIA RTX GPU가 필수입니다. (RTX 3070 이상 권장, VRAM 8GB+) AMD GPU에서는 동작하지 않습니다. 이 장은 해당 환경이 없으면 읽고 넘어가도 괜찮습니다.

항목요구
OSUbuntu 22.04 / 24.04 (Windows도 가능하나 Ubuntu 권장)
GPUNVIDIA RTX 계열, VRAM 8GB 이상
드라이버Isaac Sim 요구 버전 이상
저장공간약 50GB+ (Isaac Sim 에셋 포함)
입력 장치SO-101 리더 암 (또는 키보드/게임패드)

설치 개요#

버전 의존성이 큽니다

Isaac Sim과 Isaac Lab은 버전 조합에 민감합니다. 아래는 개요이고, 반드시 LeIsaac 공식 문서의 최신 설치 절차를 따르세요.

1. Isaac Sim + Isaac Lab#

NVIDIA 공식 문서에 따라 Isaac Sim을 설치하고, Isaac Lab을 클론해 ./isaaclab.sh --install 로 설정합니다.

2. LeIsaac 설치#

bash
git clone https://github.com/LightwheelAI/leisaac.git
cd leisaac
pip install -e .

3. 씬(scene) 에셋 준비#

LeIsaac은 주방·테이블 등 미리 만들어진 씬을 제공합니다. 문서 안내에 따라 에셋을 다운로드해 지정된 경로에 배치합니다.

데이터 수집 흐름#

text
[1] 씬 로드          Isaac Lab에 SO101Follower + 작업 물체 배치
      ↓
[2] 원격조작 수집     리더 암(또는 키보드)으로 시뮬 로봇 조작 → HDF5 저장
      ↓
[3] 포맷 변환        HDF5 → LeRobotDataset
      ↓
[4] 정책 학습        lerobot-train (13장) 또는 GR00T 파인튜닝
      ↓
[5] 실기 배포        lerobot-rollout (14장) + 실기 데이터로 파인튜닝

1) 원격조작으로 수집#

LeIsaac은 대략 다음 형태의 실행 스크립트를 제공합니다. (정확한 인자는 공식 문서 확인)

bash
python scripts/environments/teleoperation/teleop_se3_agent.py \
    --task=LeIsaac-SO101-PickOrange-v0 \
    --teleop_device=so101leader \
    --port=/dev/ttyACM1 \
    --num_envs=1 \
    --device=cuda \
    --enable_cameras \
    --record \
    --dataset_file=./datasets/pick_orange.hdf5

리더 암을 손으로 움직이면 시뮬레이션 속 팔로워가 따라옵니다. 텔레오퍼레이션 감각은 실기와 똑같습니다.

리더 암 없이도 가능

--teleop_device=keyboard 로 키보드 조작이 가능합니다. 정밀도는 떨어지지만 파이프라인 학습 목적에는 충분합니다.

2) LeRobot 포맷으로 변환#

bash
python scripts/convert/isaaclab2lerobot.py \
    --dataset_file=./datasets/pick_orange.hdf5 \
    --repo_id=myname/sim_pick_orange

변환 결과는 11장에서 본 것과 동일한 LeRobotDataset 구조입니다. 그래서 이후 학습 과정이 완전히 동일합니다.

3) 학습#

bash
lerobot-train \
    --dataset.repo_id=myname/sim_pick_orange \
    --dataset.root=./datasets/sim_pick_orange \
    --policy.type=act \
    --policy.device=cuda \
    --steps=60000 \
    --output_dir=outputs/train/act_sim_pick

Sim2Real 격차 줄이기#

시뮬레이션에서 완벽하던 정책이 실기에서 무너지는 것은 매우 흔합니다. 원인은 대체로 세 가지입니다.

격차증상완화 방법
시각 격차렌더링 영상과 실제 카메라 영상의 질감·조명 차이도메인 랜덤화(조명·텍스처·카메라 노이즈), 실기 데이터로 파인튜닝
동역학 격차시뮬레이션이 마찰·백래시를 정확히 모사하지 못함시스템 식별, 액션 노이즈 추가
기구 격차시뮬 URDF와 실물 조립 오차캘리브레이션 정확도 향상 (8장)
실무에서 잘 통하는 레시피
  1. 시뮬레이션에서 수백~수천 에피소드를 자동 생성해 사전학습.
  2. 실기에서 20~50 에피소드만 수집.
  3. 사전학습 모델을 실기 데이터로 파인튜닝.

실기만으로 200 에피소드를 모으는 것보다 훨씬 적은 노력으로 비슷하거나 더 나은 성능이 나오는 경우가 많습니다.

실습 — 브라우저 시뮬레이터로 궤적 만들기

Isaac Lab이 없어도 궤적 데이터 수집의 감각은 익힐 수 있습니다.

  1. 3D 시뮬레이터의 "녹화" 탭을 엽니다.
  2. 녹화 시작을 누르고 IK 타깃을 드래그해 큐브를 집어 상자에 넣는 동작을 수행합니다.
  3. 녹화 정지 후 JSON 내보내기를 누르면 타임스탬프별 관절 값이 담긴 파일이 저장됩니다.
  4. 이 JSON은 scripts/trajectory_to_lerobot.py로 LeRobotDataset 형태로 변환해 볼 수 있습니다. (영상은 없으므로 상태-행동 학습 실험용)

실기 데이터 수집에서 "일정한 속도로, 일관된 경로로" 움직이는 것이 왜 어려운지 체감할 수 있습니다.

클라우드에서 돌리기#

GPU가 없다면 클라우드 옵션도 있습니다.

  • AWS + Isaac Sim + ROS 2 — 원문 위키가 링크하는 참고 문서에서 클라우드 로봇 개발 파이프라인을 다룹니다.
  • Hugging Face Jobs — 데이터 수집은 못 하지만 학습은 클라우드 GPU로 가능합니다. (13장)
